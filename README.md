# Udemy Clone – HTML & CSS Project

This project is a **Udemy homepage UI clone** built using **HTML5 and CSS3** as part of my web development learning through a Udemy course.

The goal of this project was to practice **layout design, Flexbox, UI structure, and styling techniques** by recreating a simplified version of the Udemy website interface.

---

## 🚀 Project Features

* Responsive navigation bar with search bar
* Course recommendation section
* Popular courses section
* Topic suggestion tags
* Promotional banner image
* Footer with multiple navigation links
* Clean UI layout inspired by Udemy

---

## 🛠 Technologies Used

* **HTML5** – Webpage structure
* **CSS3** – Styling and layout
* **Flexbox** – Layout alignment and responsiveness
* **Google Fonts** – Typography
* **Font Awesome** – Icons
